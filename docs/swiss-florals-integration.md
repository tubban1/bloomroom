## 原下载中发现的错误

- Amaryllis 实际为同名剑模型，已替换为 PINK AMARYLLIS。
- Olive Branch 实际为沉船；搜索并检查的平面图案及树干扫描不适合插花，暂不加入橄榄枝。
- Rosehip bud 是没有三角面的点云；另一个 Rosa chinensis 模型是盆栽灌木，不能当作蔷薇果枝，暂不加入。
- 原 Dahlias 是 CC BY-NC；原 Wild Eryngium 是 CC BY-NC-ND。两者已替换为允许修改的 CC BY 来源。
- 原松果并非落叶松枝，系统准确标为松果。
- 水仙素材的多个纹理网格不是可随意舍弃的重复精度层；保留完整花冠表面后再简化。

原下载备份在 `.asset-sources/swiss-originals/`，错误的未发布模型另行存放于 `.asset-sources/`；这些目录排除 Git 和 Vercel 发布。完整来源、作者、实际授权及修改说明见 `public/models/credits.json` 与 `docs/swiss-model-sources.json`。洋牡丹实际为 Free Standard，已纠正原先错误的 CC BY 标注。

## 系统接入

- 主花、配花、叶材分类；真实模型预览；点击直接自动摆放。
- 中、英、德、法花材名；选择、撤销、尺寸、高度、±60°倾斜、容器切换与明信片数据均使用原系统流程。
- 保留原始纹理；大丽花默认使用与粉色选项一致的花瓣色校正，避免扫描贴图在当前灯光下呈褐色；其他花材保留原始自然色；洋牡丹、大丽花、朱顶红、大星芹仅提供真实存在的白、粉、红、黄、橙等品种色；水仙与刺芹保持原色。
- 侧栏只挂载可见卡片的预览画布，避免增加花材后超过浏览器 WebGL 上下文上限。
- 七款发布模型合计约 9 MB；水仙与松果保留完整纹理后简化几何，大星芹按材质合并节点，纹理限制为 512 px。
