# Bloomroom 视觉方向与交互参考

日期：2026-09-29  
参考产品：[FORi Flower Studio](https://fori-flower-studio.com/)

## 目标

让插花过程既好操作，也能持续产出清楚、完整、愿意保存和分享的作品。当前 Bloomroom 的 3D 花材在拖动和整体视觉上都没有形成优势；FORi 的平面插画反而更容易读懂花型，也让作品看起来统一。建议保留空间编辑的优点，同时把最终画面转向受控的插画表现。

## 建议视觉方向：受控的 2.5D

- **花头与叶片采用屏幕朝向的插画面片**：保持花型正面可读，避免用户转动视角或碰巧从背面看到花头。面片可以按相机方向做轻微变化，不必所有素材完全僵硬地正对镜头。
- **保留 3D 花茎、枝条、花器和遮挡关系**：用轻量的空间深度、枝条倾斜和前后层次支撑摆放感，阴影则保持柔和克制。
- **锁定正面正交视角**：将编辑重点放在构图，而不是 3D 相机控制。用户拖动花枝时，位置、比例和前后层次要容易判断。
- **统一素材语言**：花材卡片、画布中的花、容器和导出卡片来自同一套插画系统。避免写实模型、简笔图标和低细节几何体混搭。若保留下载的真实模型，先统一材质、光照和镜头；否则以一致的插画素材作为主路径。
- **提升作品在画布中的比重**：减少单枝花和花器周围的大块空白；让多枝组合成为主角，并以花束轮廓、花材比例和层次形成明确构图。中性背景可保留，但建议采用更温和的纸感底色及少量可选背景。

### 构图与素材规则

1. 花头有明确的正面识别度，并为不同品种保留轮廓差异；朝向由系统控制为主，用户可做有限微调。
2. 花枝在花器口自然汇聚，主花、配花和叶材的高度及分布形成层次，不要像互不相关的独立图标。
3. 花材缩略图与画布中的颜色、比例、姿态一致，用户可预期添加后的效果。
4. 容器与花束包装共用相同的材质、阴影和描边规则。

## FORi 工作室观察

以下是 2026-09-29 在公开工作室页面中实际操作观察到的状态。仅记录对 Bloomroom 有参考价值的行为与信息架构。

### 侧栏与选择层级

- 工作区分成“选花材”“调整花材”“选择容器”三个明确步骤，当前步骤显示在侧栏，画布仍持续可见。
- 花材按“主花 / 配花 / 叶材”分类。类别切换后只显示该类花材；卡片同时显示名称、英文名和添加符号，列表可继续滚动。
- 添加花材后，“调整花材”提供当前枝条下拉选择，避免只能通过画布命中小目标来编辑。
- 容器分成“花器 / 花束 / 想像力”。花器有多种器型与三种颜色；花束有 Paper、Canvas、Naked；想像力类有 Mug、Vintage TV、Poodle、Typewriter 等非传统载体。
- 每一步都直接作用于同一画布，选择结果不需要离开工作区再确认。

### 单枝编辑与画布反馈

- 选中枝条后提供花色选项、花材高度滑杆、倾斜角度滑杆、前后层级按钮和移除操作。
- 画布提示“点选花材、拖曳调整位置”；枝条也有方向键移动入口，给精细调整提供替代方式。
- 有上一步与取消选择操作；顶栏提供重新开始、清空花材、放大画布和背景切换。
- 背景目前提供默认灰与近黑深灰，改背景时构图仍留在工作区。

### 完成与分享

- 完成操作打开礼物卡片弹窗，仍能返回编辑。
- 可填写收件人、祝福语和署名；祝福限制为最多三行，并解释换行如何计数。
- 预览准备完成后可下载/分享竖版图片和明信片文件；还提供约 8 秒的创作过程视频。
- 分享不是脱离编辑器的孤立功能，而是把已完成构图带入带有个人信息的成品格式。

### 页面与设备入口

- 顶部提供语言切换；页脚和菜单入口连接关于页面、作品分享/画廊及品牌内容。
- 在用户提供的桌面、画廊、关于和手机截图中，工作室仍围绕画布组织；移动端将画布置顶，花材工具移到下方横向浏览。屏幕空间因此分配给当前任务，而非把桌面双栏缩得很窄。

## 对 Bloomroom 的应用建议

### P0：优先解决构图与操作反馈

- 固定正面视角，并换成屏幕朝向的插画花头；保留枝条/花器空间关系。
- 放大画布主体、缩短空白等待感；首次进入时给一个明确的空状态和可快速尝试的起步选择。
- 将拖动目标做大，选中枝条显示清楚的把手/选中态；拖动时即时预览，松手后保留稳定反馈。
- 补充键盘方向键微调、撤销/重做、取消选中和易发现的移除操作。

### P1：整理选择面板

- 采用主花、配花、叶材分类；卡片显示插画预览和简短名称，选中后明确显示已加入。
- 将“添加花材”和“编辑当前花材”分成两种清楚状态。编辑区通过列表选择枝条，并提供少量高价值控制：颜色、长度/高度、角度、前后顺序、移除。
- 容器可按花器、花束包装、趣味容器分类；颜色和器型分开选择，避免选项挤成无层级网格。
- 每个类别在窄屏仍可横向浏览；编辑控件使用底部面板或抽屉，确保画布保有足够空间。

### P2：把作品变成有完成感的礼物

- 增加低干扰的背景选项和画布放大模式。
- 完成态提供返回编辑、简洁预览、下载图片；之后再考虑祝福语卡片、明信片版式和过程视频。
- 保存导出画面使用与编辑器相同的花材插画、容器、配色和构图，不要导出时突然换一套视觉语言。

## 不照搬的部分

FORi 的多语言、品牌页、社群画廊和完整贺卡导出服务于它自己的品牌目标。Bloomroom 应优先借鉴其**渐进式选择、类别组织、可逆操作、编辑控制与完成反馈**，再按现有产品范围决定功能；不必一次性复制所有花材数量、文案或页面。

## 实施顺序与验收

1. 先统一花材插画方向与固定镜头，再调整默认构图和花器比例。
2. 之后完善花材分类、当前枝条选择和编辑控件，再打磨触屏交互。
3. 最后补充背景、完成/导出流程，并分别检查桌面和手机布局。

验收时至少确认：新增花材能立即看清且可拖动；选中、拖动、缩放/高度、角度与前后关系都有明确反馈；所有控制在窄屏可触达；花材卡片和成品画面风格一致；刷新或返回编辑不会意外丢失当前构图（若产品状态设计为自动保留）。

## 当前迭代与后续优化路线图

更新日期：2026-09-30

### 本次完成

- 将花枝调节移到画布主界面：右上角始终提供 Adjust flowers 入口，点花也可直接打开；调节卡内可以在已有花枝间切换。左侧栏只保留花材与容器。
- 修复 Paper 与 Vase 互换时陶瓷花瓶只剩瓶口的问题；不同器型切换时重新建立 3D 模型，瓶身和花枝会一起正常显示。
- 纠正纸包比例：从花头附近展开、正面下凹露出花材、向下收至绑扎点；单枝与多枝按花量调整纸套宽高，避免单枝花被过大的纸筒遮住。侧栏缩略图重新取景，展示完整纸包与花头。
- 花束包装第二款明确为纸包加蝴蝶结，卡片缩略图与主画布共用同一个模型；保留旧的 `canvas` 分享链接标识，旧作品仍可打开。
- 花器、纸包都可选一组适合各自材质的颜色，并可调节 25%–100% 透明度。选择会进入撤销/重做历史和分享链接；透明效果在画布和当前选中容器的缩略图中同步显示。
- 手机端容器分类与外观控制常驻在面板上方，器型列表独立滚动，避免选中包装后颜色和透明度控件滚出视野。

### 下一步建议

| 优先级 | 优化方向 | 具体工作 | 验收重点 |
| --- | --- | --- | --- |
| P0 | 花材视觉统一 | 收敛程序花、下载模型和缩略图之间的差异；以花头正面可读的 2.5D 表现为主，统一边缘、色彩和阴影，再逐种替换低辨识度花材。 | 同一种花在选择卡、画布和导出图里看起来一致；不因转动容器而露出难看的背面。 |
| P1 | 拖动与旋转分工 | 把“移动单枝”和“旋转整束”做成明确状态，增加更大的触控命中区、可见的选中把手及键盘微调；减少两种手势互相抢操作。 | 鼠标、触屏都能稳定拖枝；旋转时枝条一起动且不误选；取消/撤销有反馈。 |
| P1 | 自动保存草稿 | 将花材、位置、容器、颜色、透明度和旋转角度写入本地草稿；重新打开时可恢复，并给“新建作品/清空”保留明确入口。 | 刷新、意外关闭后仍能恢复最近草稿；恢复不会覆盖可复制的分享链接。 |
| P2 | 构图起步辅助 | 丰富按风格、色系或场景组织的预设；支持从当前花材一键生成疏密、主次和高低不同的起始构图，之后仍能逐枝修改。 | 空画布能很快变成可编辑作品；生成结果不超出已选花材与真实花色。 |
| P2 | 成品导出 | 提供适合分享的画幅、背景、边距和高清导出；完成页保留返回编辑，后续再加入祝福卡片版式。 | 导出与画布构图、颜色和透明度一致；桌面与手机都不裁掉花头或容器。 |
| P3 | 性能与无障碍打磨 | 按需渲染或延迟加载不可见的 3D 缩略图；检查低性能手机帧率、键盘焦点、滑杆读数和减少动态效果偏好。 | 首次可操作等待更短；核心流程可用键盘完成；移动端拖动不导致页面误滚。 |

建议按 P0 → P1 → P2 推进：先让花材整体变得清楚、统一，再减少操作冲突并确保作品不丢，最后扩展构图和成品分享。每一阶段都同时用桌面鼠标和手机触屏验收。
